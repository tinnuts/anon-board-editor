# 匿名版编辑器

一个仿 X 岛 / 蓝岛 / 4chan 版面的**匿名串编辑器**：建角色、建串、逐楼发帖，最后把整个串**导出成图片**。

纯前端，零构建、零后端（`server.js` 只是个静态文件服务器），所有数据存在浏览器本地。

## 功能

- **角色管理**
  - 新建角色自动生成 5 位乱码（大小写字母 + 数字，排除 `I l 1 O 0`，且不会是纯数字）
  - 可改角色名、乱码、别名（**别名可手填，也可一键随机生成乱码**，全局大小写不敏感去重）、配色、是否显示名字、角色设定
  - 楼内显示为「角色名 + 乱码」，或只显示乱码
- **匿名串管理**
  - 每个串有自己的六位数编号，首楼显示 `No.<编号>000`，之后 `001`、`002`…
  - 楼主标识文字与配色可自定义
  - 列出自己创建的所有串，可编辑/删除
- **编辑器**
  - 楼层列表，逐楼发表/编辑/删除
  - 发帖时可直接选择角色，或直接新建（新建即生成乱码）
  - 内置 89 个 X 岛(hacfun)颜文字，支持添加自定义颜文字与批量删除
  - 内容里可插入图片
- **导出图片**
  - 选择导出楼层范围（如 1-10 层）、图片宽度
  - 整体/楼层背景色、边框颜色与宽度、圆角、四边独立开关
  - 6 类文字（串号、串标题、楼层号、角色名、楼主标识、正文）各自独立的字体/字号/颜色/粗体，可用自定义字体文件
  - 头部元素的垂直微调（`-20 ~ +20 px`），用于肉眼对齐不同字体的字形高度
  - **实时预览**，确认后导出 PNG
- **数据安全**
  - 数据在 `localStorage`，自定义字体在 `IndexedDB`
  - 页头「导出数据 / 导入数据」可把全部数据存成 JSON 备份与迁移

## 三种用法

### 1. 电脑上本地跑

```bash
node server.js            # 默认 8080 端口，可用 set PORT=8090 改
```

Windows 下也可以直接双击 `start.bat`（显示窗口）或 `start-hidden.vbs`（无窗口），会自动打开浏览器；`stop.bat` 停止服务。

也可以不用服务器，直接双击 `index.html` 打开（`file://` 下同样能用，只是不能用 ES 模块之类的东西，本项目没用到）。

### 2. 手机单文件版（不需要电脑、不需要联网）

```bash
node build-single.js      # 或双击 build-phone.bat
```

生成 `匿名版编辑器-手机版.html`（约 258 KB，`html2canvas` 全部内联，零外部依赖）。把这个文件发到手机，用浏览器打开即可；浏览器菜单里「添加到主屏幕」可以当 App 用。

> 注意：手机浏览器的 `file://` 数据是跟文件绑定的，**不要改文件名或换目录**，并定期用「导出数据」备份。

### 3. 部署到 GitHub Pages（手机直接用网址）

仓库是纯静态的，根目录直接当站点即可：

1. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`
2. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

手机上打开这个网址，加到主屏幕就是一个"网页版 App"。数据同样只存在你自己的浏览器里，不会上传到 GitHub。

## 文件结构

```
index.html              界面 + 全部样式
app.js                  全部逻辑（全局函数式，供 onclick 调用）
server.js               本地静态服务器（纯粹图省事，也可以直接开 index.html）
vendor/html2canvas.min.js   导出 PNG（MIT）
build-single.js         打包单文件手机版
build-phone.bat         Windows 一键打包
start.bat / start-hidden.vbs / stop.bat   本地启停
```

## 数据说明

- 存储键 `anonBoardData_v7`，存角色、串、设置；
- 自定义字体存 IndexedDB 库 `anonBoardFonts`（因为字体超出 localStorage 5MB 上限）；
- 图片以 dataURL 形式存在楼层内容里，楼层越多单条数据越大，图片别放太多；
- 换设备/换浏览器不会自动同步，用「导出数据 / 导入数据」搬。
